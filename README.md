# Blame! Industrial Landscape Generator

Бесконечный процедурный генератор индустриальных ландшафтов в стиле манги *Blame!* на базе **Three.js**.

Проект создает многоярусные лабиринты, состоящие из абстрактных геометрических форм (цилиндры, конусы, обелиски, монолиты), соединенных мостами и лестницами. Мир генерируется детерминированно на основе сида, использует чанковую стриминговую подгрузку и оптимизирован для работы с тысячами объектов через `InstancedMesh`.

## 🚀 Особенности

*   **Бесконечный мир:** Процедурная генерация чанков вокруг камеры по мере движения.
*   **Детерминизм:** Один и тот же сид всегда генерирует одинаковый мир.
*   **Согласование границ (Edge Agreement):** Уникальный алгоритм, гарантирующий идеальное стыкование элементов (мостов, стен) между соседними чанками без обмена данными.
*   **Оптимизация:** Использование `InstancedMesh` для рендеринга тысяч объектов за один вызов отрисовки.
*   **Настройка в реальном времени:** Панель управления (lil-gui) позволяет менять плотность комнат, типы соединений, палитры и параметры освещения без перезагрузки.
*   **Стиль Blame!:** Flat-shading, экспоненциальный туман, монохромные/приглушенные палитры, ощущение масштаба и запутанности.

## 🛠 Технологический стек

*   **Three.js (r160+)** — 3D-рендеринг.
*   **JavaScript (ES Modules)** — чистый JS без сборщиков типов.
*   **Vite** — быстрый dev-сервер и сборка.
*   **lil-gui** — панель управления параметрами.
*   **Web Workers** (планируется) — вынос тяжелой генерации в фоновый поток.

## ⚙️ Архитектура генерации

Генерация одного чанка (`chunkGenerator.js`) происходит поэтапно:

1.  **Ярусы (Platforms):** Создание горизонтальных плит на фиксированных высотах с использованием Cellular Automata для создания органичных форм.
2.  **Комнаты и стены (Rooms & Walls):** Расстановка вертикальных препятствий и колонн внутри ярусов.
3.  **Горизонтальные связи (Connections):** Построение мостов между платформами одного уровня с гарантией связности (алгоритм Prim's).
4.  **Вертикальные связи (Stairs):** Генерация лестниц между разными уровнями с проверкой свободного пространства.
5.  **Монолиты (MegaStructures):** Крупные сквозные структуры, пронзающие несколько ярусов.
6.  **Протыкающие фигуры (Pierce):** Наклонные цилиндры, конусы и шпили, добавляющие хаос в структуру.
7.  **Декор (Decor & Micro):** Антенны, сферы, мелкие детали для наполнения пространства.

### Edge Agreement (Согласование границ)
Модуль `edgeAgreement.js` вычисляет "паспорт грани" — уникальный хеш на основе мировых координат границы чанка и сида. Это позволяет двум соседним чанкам независимо друг от друга принимать одинаковые решения о наличии проходов или мостов на стыке, обеспечивая бесшовность мира.

## 🎮 Управление

*   **Камера:**
    *   `ЛКМ + Драг`: Вращение вокруг точки фокуса.
    *   `ПКМ + Драг`: Смещение камеры (панорамирование).
    *   `Колесо мыши`: Приближение/удаление.
    *   `WASD`: Перемещение камеры (если настроено в OrbitControls).
*   **Интерфейс:**
    *   Панель настроек находится в правом верхнем углу.
    *   Кнопка `Regenerate` пересоздает мир с текущими параметрами.
    *   Кнопка `New Seed` генерирует случайный сид.

## 🚀 Запуск проекта

1.  Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2.  Клонируйте репозиторий или скачайте файлы проекта.
3.  Установите зависимости (если используется Vite):
    ```bash
    npm install
    ```
4.  Запустите локальный сервер разработки:
    ```bash
    npm run dev
    ```
5.  Откройте браузер по адресу, указанному в терминале (обычно `http://localhost:5173`).

## 🎨 Настройка параметров

Все основные параметры вынесены в `src/core/config.js` и доступны через панель управления:

*   **Seed & World:** Сид мира, размер чанка, высота яруса, радиус видимости.
*   **Layout:** Плотность комнат, стен, колонн.
*   **Connections:** Шансы появления мостов и лестниц, веса их типов.
*   **Look:** Выбор цветовой палитры (Blame, Rusted, Cold Space и др.), плотность тумана, цвет фона.
*   **Debug / Tuning:** Ручная настройка углов поворота и наклона лестниц для точной визуальной отладки.
